# Models (looping block diagrams) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A "Model" tab on six topics, each a drawn SVG block diagram that loops with CSS, with a caption and tappable labelled parts; the volcano model also gets a Three.js turntable.

**Architecture:** One shared `ModelTab` component renders a topic's variant table (plain data plus a `Scene` component per variant). Scenes are hand-placed SVG built from the `draw.ts` helpers (cabinet-projection slabs, hatch patterns, arrows, labels) and animated by keyframes in `models.css`. Each topic exports `Model` lazily so scenes stay out of the main chunk.

**Tech Stack:** React 19, TypeScript strict, SVG + CSS keyframes, Three.js 0.186 (volcano turntable only), Vitest 5 with `react-dom/server` for markup tests.

**Spec:** `docs/specs/models.md`

## Global Constraints

- CLAUDE.md: no course numbers, institution or campus names, location data, or hand-written descriptions of real places or events, anywhere including captions and commits. Captions are generic.
- Forbidden words in any caption or part text: `risk danger hazard threat warning unsafe safe deadly disaster catastroph` (the regex in `src/app/weeks/captions.test.ts`).
- No new dependencies. No animation or chart library. Three.js only in `VolcanoTurntable.tsx`.
- `src/engine/**` stays pure (no React, DOM, clock, random); the volcano profile curves live there.
- Every svg: `viewBox="0 0 400 260"`, `role="img"`, `aria-label` = the variant caption; pattern ids prefixed per scene.
- Every animated element has class `mdl` plus its effect class; loops 6 to 12 s; before-to-after loops reach the end state at the 80 % keyframe and hold to 100 %; steady loops end where they start.
- Materials: use the `MATERIAL` constants from `draw.ts`, never ad-hoc hexes, except `currentColor` for text.
- Commits: conventional, small, ending with `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`; CHANGELOG.md Unreleased entry.
- `npm run build` (lint, tests, types, bundle) passes after every task.

## Review Focus

1. Reduced motion on: every scene shows its end state and chips still select parts. Pinned in Task 1 (CSS `forwards` test) and checked by eye in Task 9.
2. Switching variants while a part is selected: selection clears, caption returns to the new variant's caption. Pinned in Task 1's ModelTab test.
3. A `data-part` in a scene that is not in the parts table, or a part with no region: the test in Task 3 greps every scene's markup both ways.
4. A phone at 412 px: labels of 11 viewBox units stay legible and nothing overflows the svg; checked by smoke screenshots in Task 9.
5. The Three.js chunk must never be pulled into the main bundle or the tests: Task 7 imports it only through `lazy()` and the markup test renders `VARIANTS` scenes only.

**Interfaces (produces):**
```ts
// draw.ts
export const MATERIAL: { basement, chalk, magma, sandstone, shale, limestone, mudstone, greensand, shaleDeep, crust, oceanCrust, mantle, soil, ash, debris, water, ice, vegetation: string }
export const mix = (hex: string, toward: string, t: number) => string   // t in 0..1, returns '#rrggbb'
export const DEPTH = { dx: 0.62, dy: -0.36 }                            // cabinet projection per unit of depth
/** The three faces of a slab whose front-left-top corner is (x, y), width w, height h, depth d. Points as "x,y x,y ..." strings. */
export const block = (x: number, y: number, w: number, h: number, d: number) => { front: string; top: string; side: string; topFill: (hex: string) => string; sideFill: (hex: string) => string }
export const arrow = (x1: number, y1: number, x2: number, y2: number) => string   // path d with a filled head, for motion arrows
export const Patterns = ({ prefix }: { prefix: string }) => JSX   // <defs> with `${prefix}-sandstone|shale|limestone|greensand` hatch patterns (copied from the brand hero SVG)
export const hatch = (prefix: string, bed: 'sandstone' | 'shale' | 'limestone' | 'greensand') => string  // `url(#...)`
export const Label = ({ x, y, lx, ly, part, children, anchor }: { x: number; y: number; lx: number; ly: number; part: string; children: string; anchor?: 'start' | 'middle' | 'end' }) => JSX
// a <g data-part={part}> with a 0.8-wide currentColor leader from (x,y) to (lx,ly) and <text font-size={11} fill="currentColor"> at (lx,ly)

// ModelTab.tsx
export interface Part { id: string; label: string; text: string }
export interface Variant { id: string; label: string; caption: string; parts: Part[]; Scene: ComponentType<{ selected: string | null }> }
export interface ModelProps { lead: string; variants: Variant[]; Aside?: ComponentType<{ variant: string }> }
export function ModelTab(props: ModelProps): JSX
```
ModelTab: state `{ variant: variants[0].id, selected: null }`; a `role="group"` button row for variants when more than one (same chip style as week08 Explore's toggles: `rounded-full border px-3 py-1 text-sm`, active `bg-foreground text-background`); the scene in a `rounded-lg border bg-card` box; the svg wrapper gets `data-selected={selected ?? ''}` and an `onClick` that reads the nearest `[data-part]` ancestor of the target and toggles it; the caption `<p>` shows `selected ? part.text : caption` with `aria-live="polite"`; the parts as `aria-pressed` chip buttons.

`models.css`: `.mdl { animation-fill-mode: forwards; animation-iteration-count: infinite; animation-timing-function: linear }`; `[data-selected]:not([data-selected='']) [data-part] { opacity: 0.35 }` and `[data-selected='x'] [data-part='x'] { opacity: 1 }` (done per-part via the `--selected` custom property set on the wrapper: `[data-part] { opacity: var(--dim, 1) }`, wrapper sets `--dim: .35` when something is selected, and the matching part is restored with an inline style from ModelTab, since CSS cannot compare attributes); keyframes `mdl-drift-right`, `mdl-drift-left` (translateX ±12 then back for steady loops), `mdl-rise` (translateY 0 → −10, hold), `mdl-sink`, `mdl-flow` (stroke-dashoffset −40 → 0, steady), `mdl-pulse` (opacity .5 → 1 → .5), `mdl-grow` (scaleY 0 → 1 with transform-origin bottom, hold), `mdl-fade-in`, `mdl-spin` (rotate for mantle cells). Durations are set per element by `style={{ animationDuration: '8s' }}`.
